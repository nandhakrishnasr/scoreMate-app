Cricket app icon pack
======================

27 icons, matching the outline style used in your app mockup (Lucide icons +
1 custom cricket bat-ball icon), exported as transparent PNGs.

Folders:
  white/128   - white icons, 128x128px  (for dark backgrounds)
  white/256   - white icons, 256x256px
  purple/128  - light-purple accent icons (#B48CF5), 128x128px
  purple/256  - light-purple accent icons (#B48CF5), 256x256px

Icon list and suggested use:
  chevron-left        back button
  settings            settings gear
  users               teams nav / team icon
  user-round          players nav
  history             match history nav
  circle-plus         new match nav
  map-pin             venue field
  trophy              competition field / match winner
  coins               toss indicator
  hand                batting hand
  pencil              edit player
  trash-2             remove player
  user-plus           add player
  play                start innings
  trending-up         wins
  trending-down       losses
  minus               draws
  calendar-check      matches played
  download-cloud      backup data
  upload-cloud        import backup
  file-spreadsheet    CSV export
  image               image export
  swords              match/versus indicator
  award               match result / trophy alt
  save                save action
  shield              team badge alt
  cricket-bat-ball    custom cricket icon (app icon / branding / empty states)

All icons are 24x24 viewBox source, exported at 128px and 256px @1x pixel
density (crisp, no anti-aliasing artifacts at these sizes). Re-export at any
other size from the source SVGs in svg_src/ if needed (also included).
