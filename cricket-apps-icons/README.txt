Gully Scorer icon pack
========================

48 icons matching your app's outline style: Lucide icons, custom cricket
motif icons, and a full set of dismissal-type icons for the "Select out
type" dialog. Exported as transparent PNGs.

Folders:
  white/128   - white icons, 128x128px  (for dark backgrounds)
  white/256   - white icons, 256x256px
  purple/128  - light-purple accent icons (#B48CF5), 128x128px
  purple/256  - light-purple accent icons (#B48CF5), 256x256px
  svg_src/    - all source SVGs (24x24 viewBox), re-export at any size/color

Nav icons (custom, cricket-themed):
  new-match-wicket     stumps + bails       -> "New match"
  teams-crossed-bats   shield with a bat    -> "Teams"
  players-batsman      stick-figure batsman -> "Players"
  history-scorecard    scorecard rows       -> "History"

"Select out type" dialog icons (custom):
  out-bowled                stumps knocked over + ball
  out-caught                fielder reaching for a catch
  out-caught-behind         keeper crouched behind stumps
  out-caught-bowled         bowler + ball looping back
  out-run-out                fielder's throw breaks the stumps
  out-lbw                    pad blocking the stumps
  out-stumped                keeper whipping off the bails
  out-run-out-mankaded       ball at the bowler's-end stumps
  out-hit-wicket              bat knocking into own stumps
  out-absent                 (mapped to Lucide user-x)
  out-retired-hurt           (mapped to Lucide heart-pulse)
  out-retired-out            (mapped to Lucide log-out)

Live scoring screen icons:
  undo                document/back icon at top of scoring screen (Lucide file-text)
  bye                 for Bye/Leg Bye runs (Lucide footprints)
  cricket-bat-ball    general cricket branding icon (custom)

Settings screen icons:
  licenses            Lucide scale (legal/licenses)
  credits             Lucide heart
  download-cloud      Backup data
  upload-cloud        Import backup
  file-spreadsheet    Export CSV
  image               Export image

Other icons (from the earlier pack):
  chevron-left, settings, users, user-round, history, circle-plus,
  map-pin, trophy, coins, hand, pencil, trash-2, user-plus, play,
  trending-up, trending-down, minus, calendar-check, swords, award,
  save, shield

All icons are 24x24 viewBox source, exported crisp at 128px and 256px.
Re-export at other sizes/colors from svg_src/ if needed.
